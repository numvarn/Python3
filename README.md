- **ไฟล์บทเรียน:** `บทที่01_ความรู้เบื้องต้นเกี่ยวกับคอมพิวเตอร์และการเขียนโปรแกรม.ipynb`
- **หัวข้อสำคัญ:**
  - **1.1 ความสำคัญของคอมพิวเตอร์** — บทบาทของคอมพิวเตอร์ในชีวิตประจำวันและงานด้านต่าง ๆ
  - **1.2 ฮาร์ดแวร์และซอฟต์แวร์**
    - 1.2.1 ฮาร์ดแวร์ (Hardware): CPU, หน่วยความจำหลัก (RAM), หน่วยความจำสำรอง, อุปกรณ์อินพุต, อุปกรณ์เอาต์พุต
    - 1.2.2 ซอฟต์แวร์ (Software): ซอฟต์แวร์ระบบ (System Software) และซอฟต์แวร์ประยุกต์ (Application Software)
  - **1.3 วิธีเก็บข้อมูลของคอมพิวเตอร์**
    - 1.3.1 การจัดเก็บข้อมูลประเภทตัวเลข (บิต, ไบต์, เลขฐานสอง) · 1.3.2 ข้อมูลประเภทอักขระ (ASCII, Unicode) · 1.3.3 ข้อมูลตัวเลขขั้นสูง (จำนวนลบและทศนิยม) · 1.3.4 ข้อมูลประเภทภาพและเสียง
  - **1.4 วิธีการทำงานของโปรแกรม** — วงจร Fetch–Decode–Execute, ภาษาเครื่อง, ภาษาแอสเซมบลี, ภาษาระดับสูง, คอมไพเลอร์ (Compiler) และอินเตอร์พรีเตอร์ (Interpreter)
  - **1.5 สรุป** · **1.6 คำถามท้ายบท** · **1.7 บรรณานุกรม**
